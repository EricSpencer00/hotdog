# hotdog

Hot dog or not hot dog. A convolutional network with 136,417 int8 parameters
and hand-written JavaScript kernels — no TensorFlow, no ONNX, no WebAssembly,
no dependencies at all. Every pixel stays on the device.

Served at [ericspencer.us/hotdog/](https://ericspencer.us/hotdog/) via GitHub
Pages. The path resolves to this repo, not to the main site repo.
